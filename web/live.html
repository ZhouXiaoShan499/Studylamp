    命令框会向设备写串口（连接时自动发一次 mic on，之后你发什么就写什么）。

    数据来自 ESP32-S3 原生 USB 串口（Web Serial），不经过任何服务器。板子上跑的是 firmware/ 那版（provider=4，腾讯云直连）：页面把 [ASR] / [LLM] / [cmd] 翻译成上面的识别结果、意图和动作。音频只走「设备 → 腾讯云」，浏览器拿不到。

    换 WiFi 不用重新烧固件：点右上角「连接 WiFi」，填 SSID 和密码后页面会通过串口发一条 wifi connect，设备把凭据写进 NVS 并立即重连；「扫描」会把设备能看到的 2.4 GHz 热点列出来。也可以在命令框直接敲 wifi status / wifi scan / wifi clear。密码只存在设备里，页面不回显、也不上传。

    连接后页面会自动发 mic on 打开电平显示（固件平时不打印 [mic] rms）。觉得不灵敏就在命令框发 vad 120，想回默认发 vad 0；也可以发 status 看完整状态。

    串口同一时刻只能被一个程序占用：连接前请关掉 idf.py monitor、串口助手。开关串口可能触发一次复位（USB-Serial-JTAG 的 DTR/RTS 语义），页面会自动重新计时并计入「复位次数」。Web Serial 只在 Chrome / Edge 桌面版可用，页面必须跑在 https 或 localhost。
