# 12 插电即用语音开关灯方案（Demo Rig v0.5）

> 目标：做一个**插上电源就能用**的小样机——对着麦克风说「开灯 / 关灯」，灯就亮 / 灭。
> 不连电脑、不装驱动、不一定要 WiFi、不一定要手机配网。
> 本文是选型与实施决策文档，不含完整代码；落地步骤见 §8 排期。

---

## 一、一句话结论

**用「离线命令词」做闭环，用「低压 MOS」驱动灯，先把 v0.5 做出来；云端大模型留到 v2。**

- 现链路（`voice_client.cpp` + PC 上的 Vosk/Ollama）**不满足插电即用**：固定录 2 秒、必须有一台常开电脑。这条只能当调试工具。
- 纯离线命令词：**0.3~0.5 s 响应、断网可用、零服务费**，正好覆盖「开灯/关灯」这类高频指令。
- 两条实现路径，**先用 A 出效果，再用 B 收口**：

| 路径 | 做法 | 新增硬件 | 工期 | 定位 |
|------|------|----------|------|------|
| **A（先做）** | 成品离线语音模块（UART 输出命令 ID）+ 现有 Arduino 固件 | ￥15~25 一个模块 | **1 天** | 立刻能演示、能验证体验 |
| **B（收口）** | ESP32-S3 + ESP-SR（WakeNet 唤醒 + MultiNet 命令词） | 0 | **3~4 天** | 项目自己的语音栈，可叠加云端对话 |

A 的灯驱动、外壳、电源、命令词表**可以整段复用到 B**，不是白做。

---

## 二、先把「插电即用」定义清楚

不写死标准就会变成"感觉通了"。满足这四条才算：

| # | 硬指标 | 验收方法 |
|---|--------|----------|
| 1 | 只有一根电源线，**没有第二台设备** | 拔掉电脑、关掉路由器，仍能开灯 |
| 2 | 上电到能识别 **≤ 5 s** | 秒表：插电 → 说"开灯" |
| 3 | 说话到灯响应 **≤ 0.5 s** | 手机录像逐帧 |
| 4 | 用户不需要看说明书 | 让没参与开发的人试一次 |

> 注意第 1 条：**云端方案天然不满足"关掉路由器仍可用"**。所以云端只能做增强，不能做开关灯的主路径。

---

## 三、与当前产品定位的关系（必须先说清）

`README.md` 和 `docs/11` 已明确：**取消 LED 照明模组**，产品转为「AI 学习桌面机器人」，灯环只做状态反馈。本方案要做"开灯关灯"，表面上和这条冲突，处理方式：

- 本方案定位为 **阶段 0 的验收样机（Demo Rig）**，不是产品形态。灯在这里是**最便宜、最直观的执行器**——用来验证"说一句话 → 设备真的动了"这条闭环，比舵机、屏幕都好验收。
- 它**不改变** `docs/11` 的对外定位，也不进产品 BOM。
- 如果后续真要做「语音台灯」这个品类（另一条产品线），需要重新评估照明模组、3C/EMC、热与结构——那是独立立项，不在本文范围。

## 四、硬件方案

### 4.1 系统框图

```text
        说话
         │
         ▼
  ┌──────────────┐   UART(单向)   ┌─────────────────┐   GPIO5   ┌──────────┐
  │ 离线语音模块  │ ─────────────▶ │  ESP32-S3-N16R8 │ ────────▶ │ 灯驱动   │──▶ 灯
  │ SU-03T / CI-03T│  命令 ID      │  状态机 / 去重   │  PWM/电平 │ MOS/继电器│
  └──────────────┘                │  蜂鸣器 / 状态灯  │           └──────────┘
         ▲                        └─────────────────┘
         │ 自带麦克风                       ▲
                                        按键 GPIO4（兜底）
```

路径 B 把左边那坨换成板载 INMP441 + ESP-SR，其余不变。

### 4.3 接线表（路径 A）

| 信号 | ESP32-S3 引脚 | 说明 |
|------|---------------|------|
| INMP441 VDD / GND | 3V3 / GND | 模块板载 LDO 时按丝印接 |
| INMP441 SCK | GPIO16 | BCLK |
| INMP441 WS | GPIO18 | LRCLK |
| INMP441 SD | GPIO17 | 数据 |
| INMP441 L/R | GND | 选左声道 |
| 按键 | GPIO4 → GND | 内部上拉，低有效 |
| 灯驱动 | GPIO5 | 经 100Ω 到 MOS 栅极 |
| 语音模块 TX | **GPIO47** | 只接单向，省一根线一个脚 |
| 语音模块 5V / GND | 5V / GND | 与主控共地 |
| 蜂鸣器 | GPIO8 | 命令确认音 |
| 状态灯 | GPIO14 | 运行 / 识别提示 |

**为什么只用单向 UART**：我们只需要模块把"命中了哪条命令"告诉 ESP32，不需要反向配置。三根线（5V/GND/TX）就能跑，接错也烧不了。

### 4.4 灯驱动

#### A. 低压 5V / 12V（推荐先做）

```text
   5V ────────────────┬──────── 灯板 +
                      │
   GPIO5 ──100Ω──┐    │
                 │    │
              ┌──┴──┐ │
              │ MOS │─┴── 灯板 −
              └──┬──┘
                 │
   GND ──10k─────┴──── GND
```

- 栅极 100Ω 限流 + 10k 下拉：**上电默认关灯**，复位期间不会闪一下。
- 灯板 > 2A 或 12V 灯带 → 换 IRLZ44N（逻辑电平），12V 单独供电、**必须共地**。
- PWM 沿用 `lighting.cpp` 现有的 4 kHz / 12 bit + Gamma + 600 ms 渐变，**一行不用改**，直接能调光。

#### B. 220V 台灯（可选，安全优先）

- 只买**成品 5V 继电器模块**（光耦隔离、10A/250VAC、带续流二极管），不要自己搭可控硅。
- 火线串继电器常开触点，零线直通；加 1A 保险丝；全部塞进阻燃盒，强电端子不外露。
- 继电器**只做开/关，不能调光**。220V 上做 PWM 调光需要过零检测 + 可控硅，不在本期范围。
- **安全红线**：断电接线、不要带电操作、强电区与低压区物理隔开；不确定就找人做。首次通电用白炽灯泡串在线路里限流测试。
- 固件侧用编译开关 `LAMP_DRIVE_RELAY=1`：`lighting` 只维护状态，不写 PWM（否则 PWM 会把继电器打成"哒哒哒"）。

## 五、命令词表（v0.5 只做 8 条）

| 命令词 | 动作 | 说明 |
|--------|------|------|
| 开灯 | 亮度恢复到上次值（默认 70%） | 主指令 |
| 关灯 | 亮度 0 | 主指令 |
| 亮一点 | +20%，上限 100 | 渐变 600 ms |
| 暗一点 | −20%，下限 5 | 渐变 600 ms |
| 最亮 | 100% | |
| 夜灯 | 5%，暖光 2700K | |
| 学习模式 | 100%，4300K | 复用 `Preset::Study` |
| 休息模式 | 35%，2700K | 复用 `Preset::Rest` |

设计约束（沿用 `docs/03` §9.2）：

- 全部 **两字以上**，禁用"开""关""好""嗯"这类单字/语气词；
- 同一命令 **1.5 s 内去重**，防模块重复上报；
- **22:00–07:00 不响应"开灯"**（只响应"关灯"），避免半夜被电视叫醒——`lighting` 里已有夜间静音思路，直接复用；
- 识别失败（低置信）→ **双短哔**，不执行，让用户知道"没听清"而不是"灯坏了"。

## 六、固件改动清单

### 6.1 路径 A（现有 Arduino 工程，约 150 行）

| 文件 | 动作 | 内容 |
|------|------|------|
| `include/voice_uart.h` + `src/voice_uart.cpp` | **新增** | UART1 @115200 8N1，解析模块帧，回调 `onCmd(uint8_t id)`；带 20 ms 组帧超时 |
| `include/config.h` | 改 | 加 `PIN_VOICE_UART_RX 47`、`VOICE_UART_BAUD`、`LAMP_DRIVE_RELAY`、`CMD_DEDUP_MS 1500` |
| `src/main.cpp` | 改 | `voiceUart::begin()` + `loop()` 里 `voiceUart::tick()`；命令映射到 `lighting::`；蜂鸣器/状态灯反馈；按键短按仍可 `toggle()` 兜底 |
| `src/lighting.cpp` | 小改 | `#if LAMP_DRIVE_RELAY` 时 `flush()/tick()` 跳过 PWM，只输出开关电平 |
| `src/pdm_mic.cpp` / `voice_client.cpp` | **不动** | 路径 A 不使用板载麦；保留给 B 与调试 |

> 不改 `lighting` 的算法、不改 `applyCommand()` 的字段——云端版将来直接复用同一套指令字段。

### 6.2 路径 B（ESP-SR，需迁 ESP-IDF）

**先说一个坑**：`firmware/idf/lamp_voice/sdkconfig` 里是 `CONFIG_IDF_TARGET="esp32"`，**不是 S3**。直接在这个工程上加 esp-sr 编不过，必须新建工程并 `idf.py set-target esp32s3` 重建。原来的 IDF 工程只能当参考。

| 步骤 | 内容 | 风险 |
|------|------|------|
| 1 | 新建 `firmware/idf/lamp_sr/`，target=esp32s3，`idf.py add-dependency espressif/esp-sr` | 依赖体积大，首次拉取慢 |
| 2 | 分区表加 `model` 分区（约 2 MB；16 MB flash 够用） | 分区表写错会反复重启 |
| 3 | I2S 读 INMP441：32 bit 槽宽 → 右移转 int16（现有 `MIC_GAIN=4` 可参考），16 kHz | 移位量需实测，错了就是纯噪声 |
| 4 | AFE 单麦：`mic_num=1, ref_num=0`，`AFE_MODE_LOW_COST`，每次喂 32 ms / 512 样本 | 参数不对识别率断崖 |
| 5 | WakeNet 唤醒词（现成中文词如"你好小智"）+ MultiNet6 命令词（8 条，拼音配置） | 自定义唤醒词要训练，周期长 |
| 6 | 命中 → 直接调灯；未命中 → 静默回 IDLE | — |

**能力边界**：8 MB PSRAM 跑 MultiNet6 没问题，但 INMP441 是**近场单麦**，1 m 内识别率最好，3 m 会明显下降。产品说明里要写"1 米内说话"。

## 七、验收标准

| 项 | 阈值 | 方法 |
|----|------|------|
| 上电可用 | ≤ 5 s | 秒表 ×10 次取均值 |
| 开灯延迟 | ≤ 0.5 s | 录像逐帧 ×10 次 |
| 识别率（安静，1 m） | ≥ 95% | 每条命令 20 次 |
| 识别率（安静，3 m） | ≥ 80% | 同上 |

| 连续通电 | 24 h 不重启、不掉线 | 串口日志无 panic |
| 上电灯状态 | 必须灭 | 插拔电源 20 次 |

## 九、风险与对策

| # | 风险 | 影响 | 对策 |
|---|------|------|------|
| 1 | 220V 强电操作 | **人身安全** | 先用 5V；强电只用成品继电器模块 + 保险丝 + 阻燃盒；断电接线 |
| 2 | 供电不足导致复位 | 说话时重启 | 5V/2A；灯与主控分开供电、共地；灯侧加大电容 |
| 3 | 上电瞬间灯闪 | 观感差、像坏了 | 栅极 10k 下拉；`lighting::begin()` 先写 0；继电器用低有效并在 init 前置高 |
| 4 | 电视/音箱误触发 | 半夜开灯 | 裸命令 + 1.5 s 去重 + 夜间只响应"关灯"；B 路径加唤醒词 |
| 5 | 模块厂商工具链锁定 | 换供应商要重配 | 命令词表与 ID 映射写在 `config.h`，换模块只改映射表 |
| 6 | Arduino 用不了 ESP-SR | B 路径卡死 | 已确认：必须 ESP-IDF，别在 Arduino 上硬啃（`docs/07` 风险 11.1 同结论） |
| 7 | 和"取消照明"的定位冲突 | 对外口径混乱 | 明确定位为 Demo Rig，不进产品 BOM，不改 `docs/11` |

## 十、今天就能做的第一步

```powershell
cd firmware

# 1. 先只验证灯（不接语音模块）
pio run -e lamp_s3 -t upload
pio device monitor -b 115200

# 串口里敲：
light on
light 30
light off
```

灯能亮、能调、能灭之后，再买模块、再接 UART。**顺序不能反**——语音和灯同时出问题，排障会翻倍。

## 十一、本方案不做的事

- ✗ 不做语音播报（没有喇叭，也不为此加喇叭）
- ✗ 不做多轮对话（v0.5 只认命令词）
- ✗ 不做手机 App（配网都不需要，更不需要 App）
- ✗ 不做 220V PWM 调光（需要过零检测，风险与收益不成正比）
- ✗ 不改 `docs/11` 的产品定位
