## 0. 两阶段总览

| | **第一阶段：语音交互** | **第二阶段：摄像头 + 语音一体化** |
|---|---|---|
| 目标 | 说话 → 灯/网页有反应 | 灯自己“看 + 听 + 说” |
| 麦克风 | INMP441 | CAM12 的 UAC 咪头 |
| 喇叭 | 无（浏览器朗读） | CAM12 的 UAC 喇叭 |
| 摄像头 | 不接 | CAM12 → 板载 USB 口（ESP32-S3 当 Host） |
| 灯代码 | 不改 | 新增 ESP-IDF 工程（`usb_stream`） |
| 电脑 | 可选（看网页） | 不需要（单机） |
| 周期 | 1–2 天 | 3–4 周 |
| 当前状态 | 按键/灯已确认；差 8/10 与 L/R | 未开始；先做 P0 spike |

```text
第一阶段：INMP441 → ASR → 意图 → GPIO5        （摄像头不接）
第二阶段：CAM12（UVC+UAC）→ ESP32-S3 Host
          ├─ 视频 → 网页/在场检测
          └─ 咪头 → ASR → LLM → TTS → 喇叭   （INMP441 移除）
```

## 1. 第一阶段：语音交互（INMP441）

### 1.1 目标

- 说“开灯 / 关灯 / 亮一点 / 暗一点 / 最亮” → GPIO5 / 网页灯状态变化。
- 网页或串口能看到识别文本；按键可开关灯。
- **不接摄像头**，先把“听 → 想 → 亮”跑稳。

### 1.2 接线（图 1 + L/R 补全）

| 模块 | 接到 | 备注 |
|---|---|---|
| 灯 3V3 / GND | 面包板 + / − 轨 | 只给按键 / RGB / INMP441，< 50mA |
| HW-483 | +轨 / −轨 / GPIO4 | 已确认可用 |
| HW-479 | −轨 / GPIO5 | G 通道；R/B 悬空；已确认可用 |
| INMP441 VDD / GND | 3V3 / −轨 | 不要接 5V |
| **INMP441 L/R** | **−轨（GND）** | **图 1 漏掉的一根；接 GND = 左声道** |
| INMP441 SCK / WS / SD | GPIO16 / GPIO18 / GPIO17 | 32 bit 槽宽 |

### 1.3 现状（2026-11-18）

| 项 | 状态 |
|---|---|
| 按键 HW-483 | ✅ 已确认可用（10/10 计数待补） |
| 灯 HW-479 G | ✅ 已确认可用 |
| 语音代码链路 | ✅ 通：`lamp_sr` 离线 3/3；`lamp_s3_tencent` ASR 886 ms；本地词表 |
| 网页 / 浏览器 TTS | ✅ 通（`lamp_s3_tencent`） |
| 8/10 可复现 | ⚠️ 未达：仓库证据只到 3/3，prob 0.14–0.47 |
| INMP441 L/R | ⚠️ 未确认：必须接 GND，否则麦克风可能全 0 |
| 开放问答 / 朗读 | ❌ 受阻：LLM `sk-` 401；命令语音不受影响 |

### 1.4 任务清单

1. 补 **INMP441 L/R → GND**，万用表量 L/R 对 GND = 0Ω。
2. 50cm 说“开灯 / 关灯”各 10 次，记录正确次数与 `prob`。
3. 按键短按 10/10 + 长按 10/10（按固件语义）。
4. 安静房间静置 30 分钟，误触发 ≤1 次。
5. 拔插电源 10/10 自动恢复。
6. 连续运行 2 小时不重启、不掉线。

### 1.5 验收与退出条件

| # | 指标 | 目标 |
|---|---|---|
| 1 | 语音命令 | ≥8/10（50cm，安静） |
| 2 | 置信度（离线） | ≥0.6 |
| 3 | 按键 | 短按 10/10 + 长按 10/10 |
| 4 | 误触发 | ≤1 次 / 30min |
| 5 | 上电恢复 | 10/10 |
| 6 | 连续运行 | 2h（阶段 0.5 目标 8h） |
| 7 | 麦克风 | L/R 对 GND = 0Ω；`mic peak` 有波动 |

> **3/3 只能算 demo，不算验收。** 第一阶段退出 = 8/10 + 按键 10/10 + L/R 确认。

### 1.6 固件怎么选

| | `lamp_sr`（ESP-IDF 离线） | `lamp_s3_tencent`（Arduino 云端） |
|---|---|---|
| 识别 | 离线 5 条命令词 | 腾讯云 ASR |
| 意图 | 固定命令 | 本地词表 →（未命中才）LLM |
| 网页 / 浏览器 TTS | ❌ | ✅ |
| 需要网络 / Key | ❌ | ✅ ASR；LLM 可选 |
| 按键短按 | 70% / 0 | 60% / 0 |
| 按键长按 | 100% 最亮 | 循环预设 |
| 适合 | 稳定命令演示 | 语音 + 网页 + 后续摄像头喇叭 |

**建议**：第一阶段先用板子上现有的固件跑 8/10；如果要做第二阶段“网页 + 摄像头喇叭”，板子最终要迁到 `lamp_s3_tencent` 或新的 IDF 工程。

### 1.7 不通过怎么办

| 现象 | 处理 |
|---|---|
| `mic peak` 全 0 | 先查 **L/R 是否接 GND**，再查 SD/SCK/WS |
| prob 太低 / 8/10 不过 | 10–20cm 重测；仍低就换 `lamp_s3_tencent` 云端 ASR |
| 按键异常 | 已确认可用；补 10/10 计数即可 |
| 开放问答 401 | 只做命令语音；换 Key 是配置，不是改代码 |

## 2. 第二阶段：摄像头 + 语音一体化（去 INMP441）

### 2.1 目标

- 灯自己完成“看 + 听 + 说”：CAM12 出画面，CAM12 的咪头收音，CAM12 的喇叭放回答。
- **去掉 INMP441**；不依赖电脑（单机）。
- 摄像头接 **ESP32-S3 的 USB 口**，由 ESP32-S3 当 USB Host。

### 2.2 接线（图 2 的修正版）

图 2 原来是“摄像头 4 线 → USB-A → 电脑”。**第二阶段把 USB-A 从电脑改到板载 USB 口**：

| 设备 | 接到 | 备注 |
|---|---|---|
| CAM12 红 / 绿 / 黄 / 黑 | USB-A：5V / GND / D− / D+ | 先万用表确认线序 |
| USB-A | **USB-C OTG → 板载 USB 口** | ESP32-S3 当 Host；不再接电脑 |
| 板子供电 / 日志 | **COM 口（UART Type-C）5V/2A** | 烧录/日志走这里 |
| CAM12 咪头 / 喇叭 | 模块 MIC / SPK 白座 | UAC 音频 |
| INMP441 | **移除** | 3V3 只给按键 / RGB |
| HW-483 / HW-479 | 不动 | +轨/−轨/GPIO4；−轨/GPIO5 |

> 关键区别：**图 2 的主机是电脑；第二阶段的主机是 ESP32-S3。** 4 根线一样，但“谁当 Host”决定要不要改代码。
>
> 5V 来源：先量板载 USB 口的 VBUS；没有 5V 就从 **5V 排针 / 有源 Hub** 给摄像头，D−/D+ 仍接 USB 口。

### 2.3 为什么必须改代码

| 事实 | 后果 |
|---|---|
| CAM12 是 USB 设备（UVC + UAC） | 需要 USB Host 枚举 |
| ESP32-S3 当前是 USB 设备（COM6/日志/Web Serial） | 不能直接读摄像头/咪头/喇叭 |
| UVC/UAC 是 USB class | 需要 `usb_host` + `usb_stream` |
| 当前 `lamp_s3` / `lamp_sr` 都没有 USB Host | 必须新增固件工程 |

**所以：第二阶段的“接线”只是把摄像头接到 USB 口；真正的工作是固件。**

### 2.4 固件方案（详见 38 号）

- 底座：**ESP-IDF 5.4.3 + `usb_stream`**（UVC + UAC，1 路摄像头 + 1 路麦克风 + 1 路喇叭）。
- 新工程：`firmware/idf/lamp_av`；从 `lamp_sr` 取按键/灯光/NVS，从 `usb_stream` 示例取 UVC/UAC，从 `cloud_asr.cpp` 移植云逻辑。
- 视频：UVC MJPEG，480×320@15fps（等时）/ 800×480@15fps（批量）；**12MP 用不上**。
- 音频：UAC 咪头 → 16k PCM → VAD → ASR → LLM → TTS → UAC 喇叭。
- 交互：按键 + WiFi 网页（摄像头流 + ASR/LLM 文本）；先半双工，AEC 后做。
- 工作量：约 40–60 小时；按 16h/周，约 3–4 周。

### 2.5 第二阶段分阶段

| 阶段 | 时间 | 做什么 | 验收 |
|---|---|---|---|
| **P0 spike** | 1–2 天 | 独立构建跑 `usb_camera_mic_spk`，只验硬件 | 枚举 / UVC 出图 / UAC 录音 / UAC 放音四项全过 |
| **P1 音频** | 2–3 天 | 咪头→ASR→LLM→TTS→喇叭；按键触发；半双工 | 说“开灯”灯亮；问一句喇叭回答 |
| **P2 视频/网页** | 2–3 天 | MJPEG HTTP 流 + 网页 + WiFi 控制台 | 浏览器看到流，10 分钟不崩 |
| **P3 整合** | 2–3 天 | 按键/RGB/NVS/重连/回声/功耗 | 8/10，2h 稳定，不接电脑 |

### 2.6 第二阶段验收

| # | 项 | 目标 |
|---|---|---|
| 1 | 摄像头 | UVC MJPEG 出图；10 分钟不崩 |
| 2 | 咪头 | UAC 16k PCM；VAD 正常 |
| 3 | 喇叭 | TTS 可听清；播放时不自触发 |
| 4 | 语音 | 命令 8/10 |
| 5 | 灯 | 按键 / RGB / 网页正常 |
| 6 | 单机 | 不接电脑；WiFi 重连正常 |
| 7 | 稳定 | 2h 不重启 |

### 2.7 风险与回退

| 风险 | 影响 | 处理 |
|---|---|---|
| CAM12 UVC 不兼容（12MP/HS-only/只支持高分辨率） | 出不了图 | P0 先验；换 2MP Full-Speed MJPEG 摄像头 |
| USB FS 带宽 | 分辨率/帧率低 | 480×320 / 800×480；MJPEG |
| 回声 / AEC | 自触发 | P1 半双工；P2 AEC |
| 板载 USB 口不输出 5V | 摄像头不亮 | 5V 排针 / 有源 Hub；量 VBUS |
| 云 Key / 费用 / 延迟 | 不可用 | 离线命令优先；Key 配置；超时降级 |
| IDF 移植工作量大 | 延期 | 先 spike；复用 `lamp_sr` / `lamp_voice` / `cloud_asr` |
| 12MP 浪费 | 成本/体积 | 产品换 2MP 或 DVP 摄像头 |

**回退**：P0 失败就不要硬上——
1. 保留 INMP441，摄像头接电脑（电脑当 Host），先做过渡验证；
2. 或第二块 ESP32-S3 当 A/V 协处理器；
3. 或换 2MP Full-Speed MJPEG 摄像头再试。

## 5. 边界

1. **第一阶段不接摄像头**；摄像头接上只会抢 USB/增加变量。
2. **第二阶段是单机**：摄像头接 ESP32-S3 的 USB 口，不接电脑。
3. **第二阶段要改代码**；本次只写方案，不动代码。
4. **12MP 用不上**：UVC 只能低分辨率 MJPEG。
5. **UAC 咪头验证通过之前，不要拔 INMP441**；`lamp_sr` 去麦还会连按键一起停。
6. **不要给摄像头 3V3**：CAM12 是 5V；5V 也不上面包板 + 轨。
