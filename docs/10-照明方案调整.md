## 1. 决策

主照明不再使用自研双色温 LED 灯板，改为：

- **5V 单色 LED 灯环**；
- 固定色温约 **4000K**；
- 通过 **MOSFET 低边开关 + PWM** 调光，范围 **1–100%**；
- 保留阅读 / 办公 / 休息 / 夜灯四档 **亮度** 场景；
- 不做 CCT 混光、不做双通道校准、不做逐台色温标定。

一句话：**把「光学 + 双色温混光」从 MVP 里拿掉，先用现成灯环把「会回应的台灯」跑起来。**

## 2. 为什么调整

1. **双色温灯板不好找**：小批量采购难，灯珠、驱动、混光结构都依赖定制；
2. **混光和校准复杂**：双通道比例、Gamma、色温一致性需要逐台校准，MVP 阶段投入产出比低；
3. **灯环是现成件**：5V 环形灯容易买、容易换、结构好装，适合快速迭代；
4. **先验证交互，不验证光学**：当前要验证的是语音、动作、灯光反馈能否形成完整体验，而不是把台灯光学做到量产级；
5. **固件更简单**：一路 PWM 代替暖白 / 冷白两路，少一套 CCT 映射和 CLI。

## 3. 新方案细节

| 项目 | 方案 |
|------|------|
| 光源 | 5V 单色 LED 灯环，约 4000K |
| 调光 | MOSFET 低边开关，4 kHz PWM，12-bit（沿用现有 LEDC 配置） |
| 亮度 | 1–100%，Gamma 2.2 感知调光 |
| 场景 | 阅读 100% / 办公 80% / 休息 35% / 夜灯 1% |
| 控制 | 按键、串口 CLI、语音指令、定时任务 |
| 色温 | 固定，不提供 CCT 调节 |
| 反馈 | 开关、亮度、场景、动作时降亮 70% 仍保留 |

> 灯环的具体直径、电流、是否自带恒流驱动，等选型后补进 BOM；如果灯环自带调光器，则 MCU 只控制 5V 通断，PWM 方案退回开关控制。

## 4. 不再使用

- 自研双色温 LED 灯板；
- 暖白 / 冷白双通道混光；
- 2700–6500K 色温调节与五档 CCT 校准；
- 依赖 CCT 的灯光配方与网站参数；
- 逐台色温标定与 CCT 传感器/校准流程。

## 7. 待定参数

- 灯环直径与安装方式；
- 灯环额定电压 / 电流 / 是否需要恒流；
- MOSFET 型号、栅极电阻、PWM 频率是否与灯环驱动兼容；
- 5V 电源剩余裕量（舵机 + 灯环 + 麦克风 + 屏幕）；
- 最低亮度是否足够夜灯、最高亮度是否满足阅读；
- 灯环的显色、频闪、热与寿命数据。

## 8. 风险

- 单色灯环可能达不到桌面阅读所需的照度 / 均匀度 / 显色；
- 低成本灯环可能存在可见频闪或色偏；
- 5V 灯环电流可能挤占舵机电源裕量；
- 去掉 CCT 后，产品少一个卖点，需要用「动作 + 语音 + 亮度场景」补回来；
- 网站和仿真在同步前仍显示旧的双色温参数，对外演示时需注明。

---

**结论**：先用单色 5V 灯环把整机交互跑通，等语音、动作、结构稳定后，再决定是否回到双色温或更高规格的光学方案。
